### About

Self-taught offensive security practitioner focused on web and network penetration testing, red team tradecraft, and bug bounty research. Building automation tooling for reconnaissance and applying AI to security workflows.

### Core Focus

- **Offensive Security:** Web/API testing, network penetration testing, Active Directory attack paths
- **Red Teaming:** Adversary emulation, initial access, post-exploitation, evasion awareness
- **Reconnaissance Automation:** Attack surface mapping and enumeration pipelines
- **AI / LLM Security:** Prompt injection, RAG security, LLM application testing
- **Detection Engineering:** Understanding attacker behavior to build better defenses
- **Low-Level Systems:** C/C++ tooling, memory and process internals
